# AI-Jobs-Switzerland

Hi! 

Similar to the [Quant jobs in Zurich](https://github.com/adrische/quant-jobs-zurich) list, I thought it was a good idea to make a list of companies hiring for AI roles in Switzerland.

Since the space is evolving so rapidly, I think there is no way for an individual to maintain such a list. Let's therefore try the community approach :)

The list of companies is available as a public and editable Google sheet under [this link](https://docs.google.com/spreadsheets/d/164yL7peCLfcXkT-oAjaikSKdD7ptiCdS9nsMyNwOtzs/edit?usp=sharing).

Feel free to edit & good luck!
